
# VENOM — Shopify Checker Bot

Telegram bot for Shopify card checking with proxy rotation, tiered access,
mass-check worker pool, and inline GraphQL checkout engine.

## Setup

```bash
git clone https://github.com/TahjirTansim/venomHitter
cd venom-bot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 main.py
